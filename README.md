# ChartQwen-R1

This repository contains the anonymous code and data artifacts for the proposed executable chart reasoning method.

## Contents

- `code/`: reward functions for executable chart reasoning.
- `scripts/`: training, inference, scoring, and data utility scripts.
- `configs/`: configuration templates with placeholder paths.
- `data/`: released training data and prompt file.

## Dependencies

The implementation is based on Python, PyTorch, and `ms-swift`. Core dependencies are listed in `requirements.txt`.

## Notes

- This anonymous release is provided to support paper review and artifact inspection.
- Model weights, benchmark images, checkpoints, external baseline implementations, and private experiment logs are not included.
- Configuration files contain placeholder paths and should be adapted to the user's own environment.
- Additional implementation details are described in the submitted paper.
